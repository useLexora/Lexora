# 模型与工具

Lexora 是你的工作台；模型、工作方法和外部工具由你选择。

## 模型服务

在设置中配置模型服务，再为任务选择模型。不同服务可能使用 API Key 或账号授权，支持的模型和能力也不同。

根据任务选择：简单整理可以使用轻量模型，复杂推理或工具执行需要相应能力的模型。图像等能力还取决于具体模型和工具，不是所有模型都支持。

服务商单独计算费用与额度。遇到连接错误时，先检查密钥、服务地址、模型名称和网络状态。

## Skills：带上工作方法

Skills 可以向任务提供可复用的方法与说明，例如一种整理材料或创作内容的流程。使用前检查来源与内容，只启用你信任且适合当前工作的内容。

Skills 不是权限隔离机制；实际文件与工具操作仍受相应授权流程约束。

## MCP：连接外部工具

通过 MCP 接入外部工具和服务。在设置中添加连接，检查连接状态与可用工具，再按任务需要使用。

外部工具可能读取数据、运行程序或发送内容到第三方服务。请检查工具来源和权限，不要将不必要的敏感信息放入任务上下文。

## 数据与授权

本地工作台不意味着所有数据都留在本机。发给在线模型的任务内容、工具结果，以及提交给外部服务的数据，会按对应服务的方式处理。

只提供必要材料，并在授权前确认操作范围。

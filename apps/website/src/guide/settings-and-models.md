# 连接模型

模型负责理解和生成内容，Lexora 负责组织任务、文件与工具。使用在线模型前，先连接服务，再启用需要的模型。想在自己的电脑上推理，参阅[本地模型](./local-models)。

## 选择接入方式

进入「设置 → 模型服务 → 添加服务」。

| 你已有的服务 | 选择方式 | 需要准备 |
| --- | --- | --- |
| 列表中的服务商 | 内置服务 | API Key，或该服务支持的 OAuth 账号 |
| 兼容接口、企业网关 | 自定义 API | API 类型、基础地址、认证信息与模型 ID |
| 已运行的本机或局域网服务 | 自定义 API | 可访问的兼容 API；详见[本地模型](./local-models#外部服务的兼容-api) |

聊天网站的订阅不一定包含 API 额度；以服务商的账号权限和计费说明为准。

## 添加内置服务

1. 搜索服务商，点击「添加」。
2. 在「配置连接」中选择「配置 API Key」或「使用 OAuth」，按提示完成认证。
3. 进入「配置模型」，开启需要的模型。
4. 点击「完成并启用」，回到任务选择模型，发送一条简短消息验证。

<GuideImage src="/guide/images/model-connection-zh.webp" alt="DeepSeek 服务的连接配置步骤与 API Key 配置按钮" caption="密钥通过单独的配置入口填写，无需粘贴到任务对话里。" :width="1024" :height="378" />

“已保存 API Key”只表示凭据已保存，不证明密钥有效、模型可用或账号有余额。服务未完成配置时，可以之后继续。

## 添加自定义 API

填写显示名称、标识符、API 类型与服务地址，再配置认证。

- **API 类型**必须与服务实际协议一致；兼容一种接口不代表兼容所有接口。
- **服务地址**是 API 基础地址，不是聊天网页地址。
- **模型 ID**是服务端接受的名称，不是任意显示名称。
- **标识符**用于区分连接，按表单规则填写；显示名称用于日常辨认。

支持发现的服务可以「同步模型」；否则使用「手动添加模型」。同步新增的模型默认关闭，手动添加的模型默认启用，最后仍应检查实际开关。刷新公共模型资料不等于为账号开通模型权限。

::: details 高级设置
只有服务要求额外请求头或确实需要覆盖参数时才调整。上下文、最大输出、原生输入能力和工具调用能力应与模型及协议相符；修改声明不会让服务获得新能力。自定义请求头按普通配置保存，不等同于加密凭据；密钥优先使用专门的认证入口。
:::

## 在任务和伙伴之间选择模型

可以在伙伴配置里设置默认模型，也可以在任务中为伙伴选择模型。头像或名称不会自动连接对应服务；没有可用默认模型时，需要主动选择。

对话、语音转写、语音合成和图像生成是不同用途。能聊天不代表能生图或朗读；语音与图像能力还需要在对应设置中选择。模型列表中的能力声明也不能替代一次实际请求验证。

## 连接本地 AI 模型

本地模型有两条路径：由插件管理模型和引擎，或连接你自行运行的兼容 API。安装、准备与限制见[本地模型](./local-models)。

## 工具调用方式

「混合调用」「代码编排」「关闭」改变模型如何调用工具，不改变任务权限。配置说明已移至[应用设置 → 工具调用方式](./app-settings#工具调用方式)。

## 检查用量与连接问题

在「设置 → 使用情况」查看 Lexora 发起的调用；账单以服务商为准。模型缺失、认证失败与超时见[常见问题](./troubleshooting)。

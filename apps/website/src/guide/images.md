# 图片理解与生成

图片输入、识图和生图不是同一种能力。先明确你要“看图”“提取文字”还是“生成或修改图片”，再选择模型与工具。

## 选择合适的能力

| 目标 | 使用方式 | 要注意 |
| --- | --- | --- |
| 看懂截图、照片或图表 | 当前模型的原生视觉，或独立识图模型 | 需要实际图片，不是只有文件名或文字摘要 |
| 比较两张图、检查界面状态 | 将相关图片一起提供，说明比较点 | OCR 文字不能证明颜色、布局或开关状态 |
| 提取图片中的文字 | OCR 或识图的文字提取能力 | 适合转录，不代替视觉理解 |
| 从描述生成图片 | 图像生成模型 | 与对话模型分开选择 |
| 参考已有图片生成或修改 | 支持参考图的编辑能力 | 支持数量与参数取决于当前服务 |

## 原生视觉与独立识图

在任务中添加图片，并说明需要观察什么。支持图片输入的当前模型可以直接理解适合其协议与预算的图片；只有路径引用时，仍需要读取图片。

打开「设置 → 模型服务」，找到「图像」区域，其中的「识图」提供：

- **按需**：当前模型支持时可优先使用原生视觉，也可使用已配置的识图目标。
- **当前模型**：使用当前任务模型的图片能力；纯文字模型不会因此获得视觉能力。
- **指定模型**：将识图交给单独选定的模型，结果再供任务使用。

独立识图适合主模型不支持图片，或希望指定视觉模型的情况。图片可能因此发送给另一个服务；请确认选择与数据范围。不要把一次识别得到的文字当成永久完整的原图证据。

## 生成与参考图

在「设置 → 模型服务 → 图像」区域的「生图」中选择可用模型。在线服务需完成认证并启用相应模型；[本地模型插件](./local-models)则需要先准备引擎和资源。

请求中说明主体、用途、风格和保存位置。需要参考图时，把图片加入任务，并明确“保留什么、改变什么”；有多张图片时分别说明作用。只有当前能力支持参考图时才能编辑，不是所有生图模型都支持。

尺寸、质量、透明背景等参数是向服务提出的要求，并非结果保证。生成成功后仍应打开实际文件检查内容、尺寸与透明效果，再用于交付。

## OCR 与文档图片

在同一「图像」区域的「OCR」中可开启独立 OCR 并配置服务；关闭时文字提取沿用识图配置。独立 OCR 会把图片发送给配置的 OCR 接口。

“把截图文字抄出来”适合 OCR；“这个选项是否已开启”“比较两张图的排版”需要视觉理解。处理扫描件或文档结构时，也可参阅[文档](./documents)。

## 失败、未知与保存未完成

| 状态 | 应该怎么做 |
| --- | --- |
| 生成失败 | 查看错误阶段、认证、额度与参数，明确原因后再重试 |
| 生成结果未知（unknown） | 请求可能已提交；先核对服务记录和已有产物，不要盲目再提交 |
| 图片保存未完成 | 服务已返回图片；先检查已保存文件、目标权限与空间，避免重复付费生成 |
| 已阻止重复生成 | 本轮存在执行中或尚未确认的请求，先处理原请求 |

停止任务或连接中断不证明远端生成已取消，也不代表费用已退回。更多排查见[常见问题](./troubleshooting#图片不能识别或生成)。

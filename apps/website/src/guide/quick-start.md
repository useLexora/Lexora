# 第一个任务

从一个小而具体的目标开始，例如「把这份会议记录整理成行动清单」。

## 1. 安装 Lexora

前往 [GitHub Releases](https://github.com/useLexora/Lexora/releases/latest)，选择与你的系统匹配的安装包：

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | Windows 安装程序 |
| Ubuntu / Debian x64 | .deb |
| Arch Linux x64 | .pkg.tar.zst |

目前没有 macOS 安装包。Linux 的原生桌宠可作为陪伴使用，不是完成任务的前提。

## 2. 连接模型

打开应用的设置，添加你使用的模型服务，按该服务要求填写 API Key 或完成账号授权，再选择可用模型。

Lexora 不提供内置的免费模型额度。模型可用性与费用取决于你选择的服务。

[了解模型与工具 →](./settings-and-models)

## 3. 发起一个任务

新建任务，描述目标、需要参考的资料和期望的成果。如果需要处理本地文件，选择合适的工作目录或关联空间。

例如：

> 阅读这份会议记录，提取已经确定的事项、负责人和仍需确认的问题。整理成 Markdown 行动清单，保存到当前工作目录。

不涉及文件时，也可以先进行一次简单对话。

## 4. 看看过程，检查成果

Lexora 会展示执行过程。遇到授权请求时，先确认工具要访问什么、执行什么，再决定是否允许。

完成后，打开生成的文件或预览产物，检查事实、格式和保存位置。可以继续补充要求，例如「把待办按优先级排序」。

重要文件在修改前请保留备份。AI 生成的结果也需要你确认。

# 第一个任务

这一章带你完成“整理一条周末步行路线”：连接模型，发出第一条消息，再把结果保存为文件。先从少量文字开始，熟悉后再处理自己的项目。

## 1. 安装 Lexora


前往 [GitHub Releases](https://github.com/useLexora/Lexora/releases/latest)，选择与你的系统匹配的安装包：

| 系统 | 安装包 |
| --- | --- |
| Windows x64 / ARM64 | 对应架构的 .exe 安装版或 .zip 免安装版 |
| Ubuntu / Debian x64 / ARM64 | 对应架构的 .deb |
| Fedora 43 x64 / ARM64 | 对应架构的 .rpm |
| Arch Linux x64 / Arch Linux ARM aarch64 | .pkg.tar.zst |
| macOS 15+，Apple Silicon（ARM64） | .dmg |

Intel / AMD 电脑选择 `x64`（.deb 标为 `amd64`，.rpm 标为 `x86_64`），ARM 电脑选择 `arm64`（.rpm 和 Arch 包标为 `aarch64`）。Linux 的原生桌宠可作为陪伴使用，不是完成任务的前提。

RPM 安装：`sudo dnf install ./Lexora-Buddy-<版本>-linux-<架构>.rpm`。Release 中的 `.sha256` 文件可用 `sha256sum -c <安装包文件名>.sha256` 校验。

### Windows 免安装版

下载对应架构的 ZIP，完整解压到本地目录后运行 `Lexora Buddy.exe`。免安装版沿用当前账户的数据位置，也会使用你已在设置中选择的数据目录；数据不会自动放在程序旁边。

更新时将新版 ZIP 解压到新目录，退出当前 Lexora 后再启动新版，不要覆盖正在运行的程序。移动程序目录后，如使用开机启动，请在设置中重新关闭再开启。隔离命令仍需按应用提示安装沙盒组件并授权 UAC；删除程序目录不会删除用户数据或该组件。

### macOS 首次安装

打开 DMG，将 `lexora-buddy.app` 拖入「应用程序」。当前安装包使用 ad-hoc 签名，尚未经过 Apple 公证；确认来自上方官方 Release 后，在终端执行：

```bash
xattr -r -d com.apple.quarantine "/Applications/lexora-buddy.app"
```

然后从「应用程序」打开 Lexora。命令只移除这个应用的隔离属性；更新后如再次被系统阻止，重新执行即可。

## 2. 连接一个模型

1. 打开左侧「设置」，进入「模型服务」，点击「添加服务」。
2. 从「内置服务」选择你使用的服务商；使用兼容接口或自己的服务地址时，选择「自定义 API」。
3. 按向导配置 API Key，或在服务支持时完成 OAuth 授权。
4. 在「配置模型」中启用至少一个模型，点击「完成并启用」。

回到任务页后，输入框旁的模型选择器应能选到刚启用的模型。只保存密钥、没有启用模型时，还不能开始对话。

::: tip 已有聊天订阅？
聊天网站的订阅和 API 额度可能独立计费。以服务商提供的接入方式为准；Lexora 不附带免费模型额度。详细步骤见[连接模型](./settings-and-models)。
:::

## 3. 先完成一次文字整理

打开「任务」，新建任务，选择可用模型，然后发送下面这段话。可以直接复制，也可以换成自己的材料。

```text
帮我把这些笔记整理成一条周末步行路线：
- 早上去面包店吃早餐，想拍下门口的风铃。
- 然后去河边散步，不赶时间。
- 下午找一家安静的书店休息。

按上午、中午、下午整理，并列出出发前还要确认的信息。
没有提供的店名、地址和营业时间不要编造。
```

这一轮不需要联网，也不需要提前准备文件。你应该看到按时段整理的路线，以及需要核实的地点、交通和营业时间。具体措辞可能不同，重点是它有没有保留你的要求。

如果出现“未发现模型”，回到「模型服务」检查服务与模型的启用状态；认证或额度报错可查[常见问题](./troubleshooting)。

## 4. 把结果保存成文件

继续发送：

```text
把这份路线保存为当前工作目录里的「周末路线.md」。
保留“待确认信息”一节，完成后告诉我保存位置。
```

这次任务需要写文件。若使用「本机只读」，先切换到允许文件修改的权限模式；需要逐项确认时可以选「人工审批」。出现审批卡片后，核对目标路径与操作，再决定是否允许。

完成后，从成果入口或工作目录打开文件，确认里面有路线和待确认事项。文件名、保存位置与实际内容都应符合要求。

## 5. 在已有成果上继续

不用新建任务，直接补一句：“下午只安排一个地点，留出休息时间，并更新文件。”也可以打开文件，选中想修改的段落，引用到输入框再说要求。

关闭后重新打开这个任务，对话仍在。想继续做其他事情时，可以把路线放进一个旅行空间，另开任务整理行李或写随笔。

接下来阅读[任务与对话](./ai-chat)，学习引用、排队与分支；需要处理自己的文件时，阅读[文件与空间](./files-and-spaces)。

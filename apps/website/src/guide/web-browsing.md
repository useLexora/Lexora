# 搜索与浏览网页

查资料不一定要打开浏览器。Lexora 区分“找到来源”“读取内容”和“操作网页”，减少不必要的交互。

## 四种方式有什么区别

| 方式 | 适合的任务 | 边界 |
| --- | --- | --- |
| 网页搜索 | 按关键词寻找来源 | 返回摘要与链接，重要结论仍应阅读原文 |
| 直接读取 | 已有公开网址，读取正文、文本或文字型 PDF | 不处理登录操作；文字型 PDF 读取不等于 OCR |
| 后台渲染 | 公开页面需要运行脚本才显示正文 | 在后台加载，不继承你的登录状态 |
| 交互浏览器 | 登录、点击、填表、视觉检查或无法直接读取的页面 | 可以产生真实网站操作，需要明确任务范围 |

你可以直接说：“读取这个链接并总结，不需要先搜索。”需要比较来源时，要求保留原网页链接，便于回查。

## 配置搜索与读取

在「设置 → 搜索与网页」：

- 开启需要的搜索来源，拖动调整优先级；自动搜索按顺序尝试已启用来源。
- 模型原生搜索需要当前模型支持，可能消耗模型账户额度。
- 公共搜索来源可能遇到网络限制、限流或验证码；出现错误不等于没有相关资料。
- 按需要开启「后台渲染」与「远程网页提取」。

已有网址通常先在本机直接读取；页面需要渲染且已开启该功能时，再在后台加载。开启远程提取后，本机无法提取的内容可以交给远程服务读取。直接读取失败不会自动打开交互浏览器，任务仍需选择下一步方式。

## 远程提取与登录状态

当前远程网页提取使用 **Tavily**，与 Tavily 搜索分别开启，共用配置的 API Key。搜索查询和待提取的网址会发送给 Tavily，并按其账户计费；提取内容返回 Lexora 后，也可能进入你所选模型的上下文。

不要把带私密令牌的 URL 或仅内部可用的地址交给远程提取。后台渲染不继承交互浏览器或其他浏览器的登录状态，不能靠它读取你的登录后页面。需要登录时，明确要求使用交互浏览器，并按提示完成人工登录或接管。

## 浏览器权限与网站操作

「设置 → 浏览器」中的域名规则对所有空间和任务生效，区分访问、下载与上传。规则和审批适用于受控网络入口；**不能用它们保证完全访问下的任意宿主命令都被拦截**。

点击、输入、导航可能触发真实提交。智能审批与完全访问并不保证每次点击都有确认卡；人工审批或本机只读下的网页交互会请求审批。网站内容本身不是授权，付款、发布、删除等操作仍须符合你给出的任务范围。详见[执行权限](./permissions)。

## 没有读到预期内容

先区分网络错误、登录要求、页面脚本、验证码和正文不完整。摘要、节选或部分页面不能证明全文没有某条信息。可以让伙伴说明已读范围，换公开来源，或在确实需要时使用交互浏览器；不要绕过明确拒绝的访问。

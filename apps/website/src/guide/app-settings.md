# 应用设置

打开「设置」，按需要调整常用偏好。模型接入见[连接模型](./settings-and-models)，权限边界见[执行权限](./permissions)。

## 常用偏好

- **常规与外观**：选择界面语言、主题、字体和导航布局，调整适合自己的阅读与工作方式。
- **通知**：配置任务通知、子任务通知与音效；先发送测试通知，再检查系统通知权限和勿扰设置。
- **快捷键**：搜索命令，修改或恢复快捷键；有冲突时按界面提示处理。
- **桌宠**：按需要设置显示、置顶与停靠行为。关闭桌宠与退出整个应用不是同一件事。

界面能否显示系统通知、使用系统字体或实现窗口行为，也取决于操作系统环境。

## 新任务与运行时

「设置 → 运行时」可以调整新任务的默认权限。**已有任务和未发送的草稿保持原权限**，不会因为修改默认值而统一切换。

也可以选择工作中发送消息时默认排队，还是补充当前工作。回答伙伴正在等待的问题不受这个默认行为影响。

模型请求自动重试适用于临时请求错误，不代表任何失败工具或外部操作都会安全重放。缓存预热只在支持且预计有收益时使用，可能增加模型用量；不需要时可关闭。

## 工具调用方式

「设置 → 运行时 → 工具调用方式」提供：

| 模式 | 行为 |
| --- | --- |
| 混合调用 | 简单操作直接调用工具，批量查询可用脚本编排并过滤结果 |
| 代码编排 | 普通工具必须通过脚本调用，要求模型能稳定生成正确脚本 |
| 关闭 | 停用代码编排，直接调用可用工具 |

变化从下一次运行生效，所有方式仍遵循任务权限。原先开启代码编排的旧配置使用混合调用，原先关闭的保持关闭；需要只通过脚本调用时，主动选择「代码编排」。

脚本并发影响任务等待和资源占用。不要把“不限制”当作总能更快；增加并发可能让电脑变慢，降低上限也不会打断已经运行的脚本。

## 查看用量

「设置 → 使用情况」展示 Lexora 发起的模型调用，可按任务或模型检查。它不扫描其他应用的历史，也不是服务商账单。

独立图像、语音或其他调用是否提供完整计量，取决于来源返回的信息；没有用量记录不等于免费。余额、最终费用和配额以服务商为准。

## 应用代理与下载代理

「设置 → 网络代理」区分两种用途：

- **应用连接**：系统代理、直连或自定义代理；支持界面接受的 HTTP、HTTPS、SOCKS5 地址，不在地址中填写账号密码。本机地址默认直连。
- **下载代理**：用于 GitHub 软件更新包和插件包，不影响其他网络请求；按启用顺序尝试，失败后使用原地址。

应用连接修改后立即生效，进行中的请求可能需要重试。下载代理不会自动解决模型 API、模型权重来源或所有外部工具的网络问题。

## 稳定版与尝鲜版更新

在「设置 → 关于」的应用更新区域选择通道：

- **稳定版**：仅接收正式版本，适合日常使用。
- **尝鲜版（Beta）**：接收正式版和 Beta；可能不稳定，也可能暂时没有 Beta 可用。

自动检查与自动下载是不同选项，**下载不等于安装，安装由你决定**。关闭自动检查时不会后台自动下载，仍可手动检查和下载；可用操作取决于当前平台和安装方式。

加入 Beta 前先[备份重要数据](./data-and-backup)。切回稳定版不会自动降级；不要只替换旧版程序就假定能读取新版数据。检查失败、安装包缺失与更新受阻见[常见问题](./troubleshooting#检查或安装更新失败)。

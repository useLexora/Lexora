# 文件与空间

空间组织相关任务，工作目录保存实际文件。把两者分清，就能知道任务归在哪里、成果存在哪里，以及下一次从哪里继续。

## 给一组工作建立空间

例如为周末出行建立“旅行计划”空间，把路线、行李和游记分别放进三个任务。这样任务各有重点，也能回到同一个主题下查找。

1. 在任务侧栏新建空间，填写容易识别的名称。
2. 需要使用已有文件时，为空间选择本地工作目录。
3. 在空间内新建任务，或在新任务的输入区选择该空间。

选择工作目录也意味着信任该目录中的上下文文件与 Skills。只选择这次工作需要的目录；额外批准某个目录的访问，不等于自动把其中所有内容加入上下文。

## 准备一个清楚的目录

可以把旅行资料这样组织：

```text
旅行计划/
├── 资料/
│   └── 城市漫步笔记.md
└── 草稿/
```

然后给出相对路径：

> 参考「资料/城市漫步笔记.md」，把周末路线保存到「草稿/周末路线.md」。原始笔记保持不变。

这种方式既方便模型找到材料，也方便你检查成果。文件树对应磁盘上的文件，重命名、复制或移动会作用于实际文件。

## 并排打开对话与资料

在工作台打开文件后，可以通过窗格菜单向左、右、上、下分屏，把任务、参考资料与预览安排在一起。多个任务分别保留自己的上下文和输入区。

想修改某段内容，直接在预览中选中并引用到目标任务。多分屏时先确认引用进入了正确的输入框，再发送要求。

## 文件引用、附件与任务引用

| 方式 | 适合什么时候使用 |
| --- | --- |
| 文件引用 | 告诉伙伴本地文件的位置，围绕该文件继续工作 |
| 选区引用 | 只讨论或修改文件中的一段内容 |
| 附件 | 把图片或文件带入本轮输入；能否直接读取取决于模型与处理能力 |
| 任务引用 | 沿用另一个任务中已经讨论过的信息 |

文件或内容被引用，不会赋予任意目录访问权限。遇到访问请求时，确认是本次工作需要的位置即可。

## 找回与继续已有工作

给任务起能描述目标的名字，例如“周末步行路线”而不是“新任务”。常用任务可以置顶；任务搜索可以按标题、空间名称或工作目录定位。

下次打开任务时，可以查看已有对话和执行记录，再告诉伙伴从哪个成果接着做。应用重启后的持续工作指的是保留进展，不代表所有中断的外部命令都会自动重新执行。

## 哪些文件需要自己备份

Lexora 的数据备份可以包含托管工作文件，但不包含你选中的整个外部工作目录。旅行目录、代码仓库、设计原稿等外部文件，应继续使用自己的文件备份或版本管理方式。

具体范围与恢复方法见[数据与备份](./data-and-backup)。

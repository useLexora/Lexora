# 认识 Lexora

想你所想，行你所行。

Lexora 是在真实桌面实践中自我演化的个人 AI Agent。不依附单一模型，不局限于代码助手；它运行在你的电脑上，在你授权的范围内调度文件与工具，把念头变成成果，让文字成为工作、创作与生活的起点。

## 从一件想做的事开始

- **整理资料**：带上会议记录、阅读笔记或项目文件，提取要点、梳理线索、生成行动清单。
- **创作内容**：从零散灵感出发，一起组织提纲、修改草稿，保存为真实文件。
- **写点代码**：阅读项目、排查报错、修改代码，用脚本解决小麻烦。
- **随便聊聊**：学点新知识、计划周末、脑暴一个离谱的点子，不必每次都带着任务来。
- **处理重复工作**：把定期整理、汇总等工作设为自动化，查看每次执行的结果。

这些是使用场景，不是固定模板。实际效果取决于你提供的上下文、选择的模型和连接的工具。

## 你的工作台，你来决定

任务承载对话、执行过程和成果；空间帮助你组织任务，并关联本地工作目录。Lexora 在你授权的范围内访问文件和执行工具，你可以查看进展、补充要求或停止任务。

选择自己的模型服务，通过 Skills 提供工作方法，通过 MCP 连接外部工具。不需要注册 Lexora 账号。

本地运行不等于完全离线：使用在线模型和外部服务时，相关内容仍会发送给你选择的服务。

## 一个有点可爱的伙伴

除了工作台，Linux 还提供原生桌宠，用陪伴和动作反馈增添一点乐趣。Windows 目前提供桌面工作台，不包含原生桌宠。

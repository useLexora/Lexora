# 认识 Lexora

Lexora 是在真实桌面实践中自我演化的个人 AI Agent。它不局限于代码助手的角色，也能陪你整理资料、打磨作品、安排日常。你说出目标，它持续推进，让文字成为工作、创作与生活的起点。

这份指南面向第一次使用 Lexora 的人。你不需要会编程；准备好一个想完成的小目标，就可以从[第一个任务](./quick-start)开始。

## 先认识三个概念

**任务**是你围绕一个目标持续工作的地方。一次任务可以包含多轮对话、工具执行、引用资料和文件成果。比如“准备周末路线”，今天确定地点，明天回来补上交通方式，仍然可以在同一个任务中继续。

**空间**用来归拢相关任务，并关联工作目录。你可以为“旅行计划”建一个空间，分别放入路线、行李清单和旅行随笔。磁盘上的工作目录保存文件，空间负责把相关工作组织起来。

**伙伴**是替你处理任务的 AI 角色。Lexora 是默认伙伴；你可以自定义其他伙伴的名字、指令、模型与能力。模型是伙伴使用的服务，换模型不需要换掉整套工作资料。

## 一次工作怎样继续下去

先说目标，再给材料。Lexora 根据上下文回复，或调用工具读取文件、修改内容、执行操作。你可以查看过程，补充要求，引用某段内容继续修改，也可以在需要时停止执行。

对话和执行记录会留在任务里。下次打开后，可以沿着已有进展继续；常用的工作方法可以保存为 Skill，反复需要的小工具可以做成插件。

::: tip 留下进展，也留下下一步
结束一轮工作前，可以补一句：“总结已经完成的内容、成果保存位置和下一步待办。”回来时更容易接上思路。
:::

## 开始前需要什么

你需要安装 Lexora，并连接至少一个可用模型。不需要注册 Lexora 账号；模型的额度与费用由你选择的服务商决定。

任务、伙伴和配置保存在本机。使用在线模型时，相关对话和文件上下文会发送给你配置的服务。更多说明见[数据与备份](./data-and-backup)。

::: details 想了解桌面之下的实现？
Vue 与 Electron 承载桌面工作台，独立的 TypeScript Runtime 承载本地 Agent。Pi 提供 Agent Loop，Rust 处理原生能力；Lexora 组织任务、上下文、权限与成果。实现细节可以从 [GitHub 源码](https://github.com/useLexora/Lexora)继续了解。
:::

# 自动化

自动化适合定期整理工作记录、汇总资料、生成待检查的草稿。先把一件事手动跑通，再把相同目标交给计划执行，会更容易发现缺失的材料或权限。

## 先完成一次相同任务

以“每周五整理周报”为例，先在普通任务中确认：记录在哪个目录、需要什么模型或工具、成果保存在哪里，以及是否会等待你批准操作。

不要只写“帮我做周报”。可以使用这种更完整的描述：

```text
读取当前空间「工作记录」目录中本周的笔记，
整理已经完成的事项、仍未解决的问题和下周待办。
保存到「周报」目录，以当天日期命名；不要修改原始记录。
缺少负责人或日期时标为待确认，不要补造。
```

## 创建计划

1. 打开左侧「自动化」，点击「添加自动化」。
2. 填写名称和提示词，选择需要的空间、伙伴与模型配置。
3. 选择执行频率和时间。
4. 检查「计划预览」中的下一次执行时间，确认后保存。

未选择空间时，每次运行会创建独立任务，并使用该任务的本地工作目录。任务要反复读取同一组资料时，关联已经准备好的空间更方便。

## 选择合适的频率

| 频率 | 适用场景 |
| --- | --- |
| 周期 | 每天、每周、每月或每年的固定日程，例如周五回顾 |
| 按间隔 | 每隔若干小时或天执行一次 |
| 单次 | 只在指定时间执行一次 |

计划还可以设置生效日期区间。修改频率后，重新看一眼预览，避免把“每周五”设置成“每天”。

## 先用“立即运行”验证

保存后，从计划的操作菜单选择「立即运行（不影响计划）」。这会执行一次任务，不改变原来的计划安排。

去「运行记录」打开这次任务，检查输出文件和执行状态。若停在「等待确认」，完成授权后再判断是否适合无人值守运行。

## 保持应用运行

计划在你的电脑上执行。Lexora 驻留系统托盘时可以继续触发；完全退出、关机或休眠时，无法按时工作。计划不是云端托管服务，也不能保证错过的时间点都会自动补跑。

自动化也使用模型额度，并受网络、模型状态、文件路径和任务权限影响。重要任务应查看每次运行记录，而不是只确认计划开关已开启。

## 暂停、修改与删除

- **暂停**：暂时停止未来触发，保留计划供以后恢复。
- **编辑**：调整提示词、空间、模型或时间，保存后检查预览。
- **删除计划**：停止未来安排，已经开始的运行不会因此取消。
- **删除运行记录**：会连同这次运行对应的任务和消息通知一起删除，操作前确认不再需要。

遇到空间或固定模型不可用，先修复关联配置，再恢复计划。具体检查步骤见[常见问题](./troubleshooting)。

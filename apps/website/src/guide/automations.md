# 自动化

自动化适合定期整理工作记录、汇总资料、生成待检查的草稿。先把一件事手动跑通，再把相同目标交给计划执行，会更容易发现缺失的材料或权限。

## 先完成一次相同任务

以“每周五整理周报”为例，先在普通任务中确认：记录在哪个目录、需要什么模型或工具、成果保存在哪里，以及是否会等待你批准操作。

不要只写“帮我做周报”。可以使用这种更完整的描述：

```text
读取当前空间「工作记录」目录中本周的笔记，
整理已经完成的事项、仍未解决的问题和下周待办。
保存到「周报」目录，以当天日期命名；不要修改原始记录。
缺少负责人或日期时标为待确认，不要补造。
```

## 创建计划

1. 打开左侧「自动化」，点击「添加自动化」。
2. 填写名称和提示词，选择需要的空间、伙伴、模型与执行权限。
3. 按本机时间选择执行频率和时间。
4. 检查「计划预览」中的下一次执行时间，确认后保存。

每次运行都会创建独立任务，不会自动续接上一次的对话。未选择空间时，使用新任务自己的本地工作目录；要反复读取同一组资料或累计成果，应关联已经准备好的空间，并在提示词里写清输入和输出路径。

## 选择合适的频率

| 频率 | 适用场景 |
| --- | --- |
| 周期 | 每天、每周、每月或每年的固定日程，例如周五回顾 |
| 按间隔 | 每隔若干小时或天执行一次 |
| 单次 | 只在指定时间执行一次 |

计划还可以设置生效日期区间。修改频率后，重新看一眼预览，避免把“每周五”设置成“每天”。

## 先用“立即运行”验证

保存后，从计划的操作菜单选择「立即运行（不影响计划）」。这会执行一次任务，不改变原来的计划安排。

去「运行记录」打开这次任务，检查输出文件、日期、保存位置和执行状态。「立即运行」仍是后台自动化，不能等待人工审批；缺少授权的操作会失败。先在普通任务或空间设置中准备必要的持久目录、域名等授权，再重新验证，不要等待自动化弹出审批卡。

自动化有自己的执行权限，默认受控执行，不会继承普通任务临时开启的完全访问。计划开启不代表所有操作都已获准；不要为了消除权限错误而盲目扩大访问范围。同一计划上一轮未结束时，新一轮可能被跳过，应在记录中核对。

## 保持应用运行

计划在你的电脑上执行。Lexora 驻留系统托盘时可以继续触发；完全退出、关机或休眠时，无法按时工作。计划不是云端托管服务。

恢复运行时会检查错过的计划，但只做有限补跑：当前窗口为 24 小时，窗口内多个到期点会合并为最近一次；超过补跑窗口的计划会跳过或过期，不会逐次补齐。失败的任务和可能已有副作用的中断操作也不会保证自动重试。重要工作请检查记录，确认后再手动运行。

自动化也使用模型额度，并受网络、模型状态、文件路径和任务权限影响。重要任务应查看每次运行记录，而不是只确认计划开关已开启。

## 暂停、修改与删除

- **暂停**：暂时停止未来触发，保留计划供以后恢复。
- **编辑**：调整提示词、空间、模型或时间，保存后检查预览；已接受的运行保留当时配置。
- **删除计划**：停止未来安排，已经开始的运行不会因此取消。
- **删除运行记录**：会连同这次运行对应的任务和消息通知一起删除，操作前确认不再需要。

遇到空间或固定模型不可用，先修复关联配置，再恢复计划。具体检查步骤见[常见问题](./troubleshooting)。

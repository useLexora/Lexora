# 语音输入与朗读

语音输入把说话内容转成文字；朗读把回复正文转成声音。两者可以分别启用，也可以使用不同来源，不要求聊天模型同时支持语音。

## 选择来源

打开「设置 → 语音」。

| 能力 | 可用来源 | 需要准备 |
| --- | --- | --- |
| 语音输入 | 可用的转写模型，包括提供此能力的插件 | 启用模型、麦克风权限与输入设备 |
| 回复朗读 | 系统声音，或可用的语音合成模型、插件 | 可用声音与音频输出设备 |

模型服务中的语音模型需要正确的用途、认证和接口支持；仅启用对话模型不够。某个服务支持聊天登录，也不表示它提供独立语音接口。系统声音由操作系统提供，可用语言和声音随设备而异。

## 设置语音输入

1. 开启「语音输入」，选择转写模型。
2. 允许系统麦克风权限，点击「测试麦克风」，观察音量是否变化。
3. 点击「试说一句」，完成录音后检查转写结果；支持语言选择的来源可以指定语言。
4. 回到任务使用语音输入，完成后核对文字再发送。

麦克风测试成功只说明采集链路可用，不证明转写模型可用。长录音前先做短句测试；中断后已识别的文字可能仍在，请先核对，避免重复补入。

## 设置回复朗读

1. 开启「语音输出」，选择系统声音或朗读模型。
2. 按来源选择声音、填写声音 ID，或调整支持的语速设置。
3. 点击「试听」，确认音量、语言和发音。
4. 在有可朗读正文的回复上使用朗读按钮；准备或播放期间可取消、停止。

声音列表加载失败时，只有在知道有效声音 ID 的情况下才手动填写。系统没有可用声音时，检查系统语音组件，或改用已配置的模型来源。

## 数据会发到哪里

使用远程转写服务时，录音会发送到该服务；使用远程朗读服务时，待朗读文字会发送到该服务。系统朗读不通过所选聊天模型；其具体语音能力由系统提供。[本地插件](./local-models)的对应推理在本机运行，但资源准备可能联网。

试说与试听也会实际调用所选来源，远程服务可能计费。选择本地语音不意味着聊天、网页工具或其他功能都离线。

## 无法录音或没有声音

- **音量不变化**：检查麦克风权限、默认输入设备、静音和设备占用。
- **能录音但没有文字**：检查转写模型是否可用、语言、凭据、额度与网络；本地来源还要检查引擎。
- **朗读没有声音**：先测试系统输出音量和设备，再检查声音 ID、模型可用性和错误提示。
- **中途断开**：保留已识别文字，修复原因后手动重试，不把中断视为服务未计费。

更多排查见[常见问题](./troubleshooting#语音输入或朗读不可用)。

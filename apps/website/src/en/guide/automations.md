# Automations

Schedule recurring work such as collecting notes, summarizing research, or preparing a draft for review.

## Set up a schedule

Describe the task in Automations, set its schedule, and choose a space, working directory, and model as needed. Run the same task manually first to check its inputs, tools, and output location.

Keep instructions specific and repeatable. For example:

> Summarize this week’s work notes into a recap and a list of next steps. Save them in Weekly reports. Do not change the original notes.

## Review each run

Check schedules, run history, task status, and outputs. A scheduled trigger does not guarantee a successful result: network access, model availability, permissions, and tools all matter.

## Keep the app running

Automations run on your computer:

- Schedules can trigger while Lexora is running, including in the system tray.
- They do not continue after you fully quit the app or shut down the computer.
- This is not a cloud-hosted task service provided by Lexora.

Keep appropriate approval checks and human review for important files or external actions.

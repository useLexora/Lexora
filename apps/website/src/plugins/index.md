# 插件开发

把常用流程做成可以安装、分享和持续迭代的插件。一个插件可以提供工作台界面、文件处理、Agent 工具、Skills 或主题，也可以组合这些能力。

## 选择起点

- **想用对话制作功能**：从[使用与制作插件](../guide/plugins)开始，描述需求，让伙伴生成源码和安装包。
- **想自己编写插件**：跟随[第一个插件](./quick-start)，创建一个可以打开和保存计数的面板。
- **已经在维护插件**：查阅[API 参考](./api)与[构建和分发](./distribution)，核对当前类型和兼容范围。

## 从目标选择能力

| 想做什么 | 从这里开始 |
| --- | --- |
| 页面、分屏面板、菜单和输入命令 | [视图与交互](./views) |
| 文件预览、编辑、保存与恢复 | [文件与文档](./files) |
| 选中材料交给对话，并定位回原文 | [引用与来源定位](./references) |
| 专用 Agent 工具、任务动作和配套 Skills | [Agent 能力](./agent) |
| 设置、私有数据和状态恢复 | [设置与状态](./settings) |
| 配色、图标、样式和装饰 | [主题与外观](./appearance) |
| 第三方库、Worker 和 WASM | [依赖与计算](./workers) |

## 理解运行边界

插件后台和视图运行在隔离的浏览器环境中。文件、网络、模型等能力通过宿主接口按权限开放。开发前先了解[核心概念](./concepts)与[权限和兼容性](./permissions)。

文档中的增量能力以对应的最低宿主版本和实际能力为准。API 主版本相同，不代表所有宿主都提供相同接口。

# 插件开发

把常用流程做成可以安装、分享和持续迭代的插件。一个插件可以提供工作台界面、文件处理、Agent 工具、模型与多模态能力、Skills、MCP 连接、NPC 或主题，也可以按显式依赖组合这些能力。

## 选择起点

- **想用对话制作功能**：从[使用与制作插件](../guide/plugins)开始，描述需求，让伙伴生成源码和安装包。
- **想自己编写插件**：跟随[第一个插件](./quick-start)，创建一个可以打开和保存计数的面板。
- **已经在维护插件**：查阅[API 参考](./api)与[构建和分发](./distribution)，核对当前类型和兼容范围。

## 理解运行边界

插件后台、视图与浏览器 Worker 运行在隔离的浏览器环境中；原生推理是单独声明、授权和监督的执行通道，不会给这些浏览器上下文开放 Node.js。文件、网络、模型等能力通过宿主接口按权限开放。开发前先了解[核心概念](./concepts)与[权限和兼容性](./permissions)。

文档中的增量能力以对应的最低宿主版本和实际能力为准。API 主版本相同，不代表所有宿主都提供相同接口。

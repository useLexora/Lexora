# 内容插槽

内容插槽由宿主负责位置和布局，插件提供隔离视图。通过 `lexora_plugin_capabilities({kind:"slot"})` 查询当前宿主支持的位置，也可指定 `target` 只读取一个位置。目录返回用途、作用范围、单选或多选策略，以及高度的最小值、最大值和默认值；不要根据 CSS 类名推测目标。

清单使用 API 3，声明 `{id,kind:"slot",target,view,height?}`。`view` 指向本插件 `resource:"none"` 的视图。内容插槽不接受 `presentation`，不通过 `placements.show/hide` 开关，本身不要求权限。

安装后由用户在插件管理的「界面呈现」中选择；单选目标替换内置内容，多选目标按用户选择顺序追加内容。未选、尚未就绪或提供者不可用时显示内置回退；没有内置内容的追加区为空。输入辅助区总高度受宿主限制，超出后滚动。

每个可见宿主位置拥有独立视图，`context.instanceId` 是所在分屏的不透明标识，可能为空。它可以关联自己发起的命令和分屏挂载，不提供任务身份、历史或输入文字。视图销毁时清理资源；临时内容不使用 `setState`，需要共享业务状态时通过自身宿主命令访问私有存储。
